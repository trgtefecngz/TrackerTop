## What exists
- `src/model.rs::Confidence`; `src/indexer.rs::resolve_edges` labels every edge (`pick_labelled`, `pick_qualified`, `pick_best_symbol`). Exact: qualified path (`Type::f`, `module::f`, `crate::a::f` when one candidate lives in that module), `Self::`, module/file path, or a name defined once in the caller's file. Heuristic: everything found by name only (another file, several candidates, Rust `.method()` on a value, case-insensitive or last-segment fallback, basename file match), and co-change edges.
- `src/db.rs`: `edges.confidence TEXT NOT NULL DEFAULT 'heuristic'`. An old index gets the column in place and `edges_generation = -1`, so the next index run rebuilds and labels every edge. Duplicate edges keep `exact` if any copy is exact.
- `src/graph.rs::CodeGraph::labelled_bfs`: one walk for neighborhoods, impact and review dependents. A symbol is listed once at its shortest distance with the best path of that length; a path is exact only when every edge on it is.
- `tests/golden.rs` + `tests/golden/<lang>/expected.json` + `tests/golden/baseline.json`. `GOLDEN_DUMP=1 cargo test --test golden -- --nocapture` prints every symbol and edge. `tests/golden/.ignore` keeps fixtures out of TrackerTop's own index.

Ground-truth conventions (also in the fixtures): a dynamic call (trait object, interface, `self.m()` that a subclass overrides) is a call to every implementation; a constructor call (`new X()`, `X()`) is a call to class `X`; a macro call is a call to the macro, and the macro body's calls belong to the macro.

## Decisions
- Exact is narrow on purpose: a bare name found only in another file is heuristic even when it is unique in the project (an import, a library function or a namesake may be meant). Result: in TS/Python/Go most cross-file edges are heuristic until imports are followed or the LSP bridge lands.
- A Rust method call on a value is always heuristic, even with one candidate (the receiver type is unknown).
- `resume` staleness uses local git only (no `gh`): the SessionStart briefing must stay under a second and work offline. A PR is "merged" when a commit after the file's last change has `(#N)` or `Merge pull request #N` in its subject. Threshold for age: 3 commits.
- The golden test fails on a wrong exact edge and on any drop below `baseline.json`; improvements are recorded by raising the baseline in the same PR.
