## Notes and decisions
- Lexer-only unit tests of the old TS scanner (`ts_code_only`, `ScanCarry`) were replaced by behavioral span tests on the same inputs. The lexer no longer exists, so its unit tests cannot pass as-is; the behavior they protected (spans unaffected by strings, comments, regex, JSX) is still tested.
- Unterminated `it(`: tree-sitter puts the call into an ERROR node. It is recorded as a one-line test without call edges, the old behavior.
- smart_grep uses Unicode simple lowercasing. Turkish dotted/dotless I (`I`→`i`, not `ı`) is not folded the Turkish way; this is a known limit.
- Markdown (`.md`) is indexed by the docs extractor, so smart_grep searches it.

## Product feedback from dogfooding (TrackerTop's own tools)
- `file_outline` and `read_symbols_batch` saved most of the reading on `typescript.rs` and `context.rs` (85-89%).
- Missing: a way to view a line range around a symbol (e.g. a whole `impl` tail or a test module) without falling back to Read; `read_symbol` on a `mod tests` would help.
- Before this run, "File not found in index" did not say whether the file existed on disk; that is fixed now.
